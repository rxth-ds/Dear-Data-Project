# Footsteps Visualised – Dear Data 100

## Project Overview

Footsteps Visualised is a creative coding project developed as part of the Dear Data 100 assessment at City St George's, University of London.

The project explores my daily walking habits over 100 days, examining how my physical activity varies over time. By collecting data on my daily step count, distance travelled and active time, I aim to identify patterns, trends and changes in my movement throughout the observation period.

Using Processing (Java), I will transform this numerical data into an interactive visualisation that represents my daily footsteps in a creative and engaging way.

## Project Objectives

- Collect and document 100 days of personal walking activity.
- Analyse variations in daily step counts, distance travelled and active time.
- Identify patterns in my walking habits, including differences between weekdays and weekends.
- Develop an interactive data visualisation using Processing (Java).
- Explore how programming and visual design can communicate everyday behavioural patterns.

## Data Collection

The dataset consists of four variables recorded daily over a period of 100 days.

| Variable | Description |
|----------|-------------|
| Date | The date on which the walking activity was recorded. |
| Step_Count | The total number of steps taken during the day. |
| Distance | The total distance travelled on foot during the day. |
| Active_time | The total time spent physically active during the day. |

The data will be organised into a structured dataset and used to develop a visual representation of my walking activity.

## Technologies Used

- **Processing (Java):** Developing the interactive visualisation.
- **Microsoft Excel:** Organising and managing the collected data.
- **GitHub:** Documenting the development process and maintaining version control.

## Project Development

The project will be developed iteratively, beginning with data collection and exploration, followed by the design and implementation of an interactive visualisation.

The final outcome will aim to communicate patterns in my daily movement through creative visual elements, allowing viewers to explore how my walking activity changes over time.
